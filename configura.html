Configura

Overview

Configura is an open-source character creator creation tool used in Godot. It allows developers to quickly integrate their 3D models and assets into an interactive character creator.

Tools used

Godot, GDScript

Platform

Windows

Duration

3 months

Team size

4

Download the Plugin!

Role: Programmer

  • Implemented separation of base model meshes and accessory meshes into their own respective scenes when reading in a 3D character model file
  • Implemented dynamic mesh loading and unloading to optimize run-time performance, reduce memory storage and smaller character save files
  • Implemented dynamic camera movement (camera will focus on the specific section of the character that is currently being edited)
  • Improved quality of life features regarding camera movement (panning and rotation)
  • Refactored an existing codebase to reduce redundancy and improve readability and maintainability
  • Created and updated code documentation for the internal team and exterior documentation for developers and artists
