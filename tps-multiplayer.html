TPS Multiplayer Demo

Overview

This project is a demo showcasing my understanding and execution of online multiplayer with server and client connections. It also demonstrates my understanding of C++ programming in Unreal Engine 5. All player movement and mechanics are programmed in C++, including shooting, aiming down sight, reloading, and dealing and receiving damage. Replication of data from server to client is also implemented purely in C++. I challenged myself to not only understand networking in Unreal Engine 5, but also to implement all features in C++, with minimal reliance on blueprints. The only use of blueprints I utilized in this project was with animation blueprints for the player animations.

Tools used

Unreal Engine 5, C++, Animation Blueprints

Platform

Windows

Duration

Less than 4 weeks

Team size

Solo Developer

Role: Gameplay Programmer

  • Programmed player controls with the Enhanced Input Subsystem, such as movement, sprinting, jumping, crouching, shooting, aim down sight (ADS), and reloading
  • Programmed replication of line tracing when shooting and replicating damage from server across all clients
  • Programmed replication of the reload animation
  • Programmed replication of the sound effect when shooting
  • Programmed replication of the muzzle flash particle effect when shooting
  • Programmed the logic behind updating weapon ammo when reloading
  • Programmed the animation blueprint for the third person character
  • Set up server to client host connection in Unreal Engine 5

Role: Designer

  • Designed and whiteboxed a simple demo level
