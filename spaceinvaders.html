Space-Invaders 3D

Overview

Space-Invaders 3D is a remake prototype of the classic Space-Invaders game. The game features local co-op split screen where two players must fend off the endless waves of enemies from destroying the nexus base. These enemies consist of a mashup of retro game characters such as Pac-Man ghosts, Super Mario's goomba, and of course, the classic Space-Invaders aliens. Both players pilot TIE Fighter ships from Star Wars. Players can shoot at alien projectiles to destroy them or block them with their active shields to prevent them from damaging the base. After each successful wave clear, players will be able pick up power ups that upgrade their ship's fire power and fire rate.

Tools used

Unreal Engine 5, Blueprints, Blender

Platform

Desktop Browser

Duration

Less than 3 weeks

Team size

2

Role: Gameplay Programmer

  • Implemented local co-op split screen feature with both mouse/keyboard and controller support
  • Implemented the player blueprint with movement, collision detection, player shooting a line trace from the gun to crosshair
  • Programmed the player's projectiles blueprint
  • Programmed the different upgrade power ups (rapid fire, burst fire)
  • Implemented an active shield to block enemy projectiles
  • Programmed the crosshair widget blueprint
  • Created and programmed the functionality for the menus (start menu, pause menu, controls menu and game over screen) with widget blueprints

Role: 3D Artist

  • Modeled all character game assets (TIE Fighter ship, Space-Invaders alien, Super Mario's goomba, Pac-Man ghost)
  • Textured all character game assets

Role: Designer

  • Designed the different upgrade power ups (rapid fire, burst fire)
  • Designed and assembled the game level with finished assets
